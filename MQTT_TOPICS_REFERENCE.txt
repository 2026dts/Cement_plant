CEMENT PLANT MQTT TOPIC REFERENCE
===================================

Location Namespace
------------------
All plant MQTT topics use this location prefix:

plant/cement-dubai/

Topic Pattern
-------------
ESP1 value/state topic:
plant/cement-dubai/esp1/<item_id>

ESP1 command topic:
plant/cement-dubai/esp1/<item_id>/cmd

ESP1 target command topic:
plant/cement-dubai/esp1/<item_id>/target/cmd

ESP1 target status topic:
plant/cement-dubai/esp1/<item_id>/target/status

ESP2 value/state topic:
plant/cement-dubai/esp2/<item_id>

ESP2 command topic:
plant/cement-dubai/esp2/<item_id>/cmd


BROKER CONNECTIONS
==================

Local Mosquitto Broker
----------------------
Host: 192.168.0.3
Port: 1883
Protocol: mqtt

Firmware files:
- esp1_materials.ino
- esp2_relay.ino

HiveMQ Cloud Broker
-------------------
Host: 5c0b21424f334243b66237dfd2f9b565.s1.eu.hivemq.cloud
Port: 8883
Protocol: mqtts (TLS)

Firmware files:
- esp1_materials_hive.ino
- esp2_relay_hive.ino

Important:
Local and HiveMQ firmware use the same MQTT topics.
Only the broker connection is different.
Upload only one firmware variant to each ESP32 board.

MQTT SUBSCRIBE EXAMPLES
=======================

Subscribe to all location topics:
mosquitto_sub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/#" -v

Subscribe to Klin temperature:
mosquitto_sub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/esp2/klin_dht_temp" -v

Publish Klin heater ON:
mosquitto_pub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/esp2/klin_heater/cmd" -m "{\"command\":\"on\"}"

Publish Klin heater OFF:
mosquitto_pub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/esp2/klin_heater/cmd" -m "{\"command\":\"off\"}"

Publish Gypsum target:
mosquitto_pub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/esp1/gypsum/target/cmd" -m "{\"target\":50}"
