CEMENT PLANT MQTT TOPIC REFERENCE
===================================

Location Namespace
------------------
All plant MQTT topics use this location prefix:

plant/cement-dubai/

Architecture
------------
Identity lives in the JSON payload, not in the topic.

Common application topics per board:
  command            incoming material commands (ESP1)
  values             live material / sensor readings
  status             device LWT, plus ESP1 dispense status (payload.type = material)
  actuator/command   incoming actuator commands
  actuator/state     outgoing actuator states

ESP2 also uses:
  override/command   resume auto / PID
  override/status    klin / klin_heater manual-override flag

OTA, reboot, version, and ThingsBoard topics stay device-level.

Host: 5c0b21424f334243b66237dfd2f9b565.s1.eu.hivemq.cloud
Port: 8883
Protocol: mqtts (TLS)

Firmware files:
- esp1_materials_hive.ino

Important:
Local and HiveMQ firmware use the same MQTT topics.
Only the broker connection is different.
Upload only one firmware variant to each ESP32 board.


ESP1 COMMON TOPICS
==================

Command (backend -> ESP1):
plant/cement-dubai/esp1/command

Payload:
{"type":"material","material":"gypsum","action":"target","target":50}

material is one of: gypsum, clay, iron_ore, sand

Live values (ESP1 -> backend):
plant/cement-dubai/esp1/values

Payload (Consolidated Materials):
{
  "type": "materials",
  "values": {
    "gypsum": 6.04,
    "clay": 0.0,
    "iron_ore": 0.0,
    "sand": 4.26
  },
  "unit": "g"
}

Status (ESP1 -> backend):
plant/cement-dubai/esp1/status

Device LWT / connect:
{"value":"online"}
{"value":"offline"}
{"value":"rebooting"}

Dispense status (same topic, distinguished by type):
{"type":"material","material":"gypsum","target":55.0,"status":"dispensing"}
{"type":"material","material":"gypsum","target":55.0,"status":"done"}

Lime stone gate command (backend -> ESP1):
plant/cement-dubai/esp1/actuator/command

{"type":"actuator","actuator":"lime_stone","command":"open"}
{"type":"actuator","actuator":"lime_stone","command":"close"}

Lime stone gate state (ESP1 -> backend):
plant/cement-dubai/esp1/actuator/state

Payload (Consolidated Actuators):
{
  "type": "actuators",
  "values": {
    "lime_stone": "open"
  }
}


ESP2 COMMON TOPICS
==================

Live sensors (ESP2 -> backend):
plant/cement-dubai/esp2/values

Payload (Consolidated Sensors):
{
  "type": "sensors",
  "values": {
    "klin_dht_temp": 34.0,
    "klin_dht_humidity": 60.5,
    "cooler_dht_temp": 28.2,
    "cooler_dht_humidity": 55.1,
    "preheating_tower_dht_temp": 45.3,
    "preheating_tower_dht_humidity": 40.2,
    "vibration_sensor": 0.05
  }
}

Actuator command (backend -> ESP2):
plant/cement-dubai/esp2/actuator/command

{"type":"actuator","actuator":"crusher","command":"on"}
{"type":"actuator","actuator":"crusher","command":"off"}
{"type":"actuator","actuator":"klin_heater","command":"on","mode":"auto"}

actuator is one of:
crusher, conveyor_1, conveyor_2, conveyor_3, conveyor_4,
klin, klin_heater, heat_blower,
preheating_tower_fan, preheating_tower_heater,
vibration_motor, ball_mill_1, ball_mill_2

Actuator state (ESP2 -> backend):
plant/cement-dubai/esp2/actuator/state

Payload (Consolidated Actuators):
{
  "type": "actuators",
  "values": {
    "crusher": "off",
    "conveyor_1": "off",
    "conveyor_2": "off",
    "conveyor_3": "off",
    "conveyor_4": "off",
    "klin": "off",
    "klin_heater": "off",
    "heat_blower": "off",
    "preheating_tower_fan": "off",
    "preheating_tower_heater": "off",
    "vibration_motor": "off",
    "ball_mill_1": "off",
    "ball_mill_2": "off"
  }
}

Device status:
plant/cement-dubai/esp2/status
{"value":"online"}
{"value":"offline"}
{"value":"rebooting"}

Override resume (backend -> ESP2):
plant/cement-dubai/esp2/override/command
{"type":"override","actuator":"klin","command":"auto"}
{"type":"override","actuator":"klin_heater","command":"auto"}

Override status (ESP2 -> backend):
plant/cement-dubai/esp2/override/status

Payload (Consolidated Overrides):
{
  "type": "overrides",
  "values": {
    "klin": false,
    "klin_heater": false
  }
}

MQTT EXAMPLES
=============

Subscribe to all location topics:
mosquitto_sub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/#" -v

Subscribe to ESP2 sensors:
mosquitto_sub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/esp2/values" -v

Publish crusher ON:
mosquitto_pub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/esp2/actuator/command" -m "{\"type\":\"actuator\",\"actuator\":\"crusher\",\"command\":\"on\"}"

Publish klin heater OFF:
mosquitto_pub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/esp2/actuator/command" -m "{\"type\":\"actuator\",\"actuator\":\"klin_heater\",\"command\":\"off\"}"

Publish gypsum target:
mosquitto_pub -h 192.168.0.3 -p 1883 -t "plant/cement-dubai/esp1/command" -m "{\"type\":\"material\",\"material\":\"gypsum\",\"action\":\"target\",\"target\":50}"
